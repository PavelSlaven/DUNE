## Ответ ведущего на остановку P6AT в прогоне A

1. **Причина остановки — ошибка ведущего.** Каталог `.tmp/deps` был скопирован из другой рабочей копии вместе с кэшами CMake и штампами установки, в которых записан путь той рабочей копии. Ведущий удалил `.tmp/deps/build`, `.tmp/deps/installed` и `.tmp/deps/prefix` и пересобрал зависимости сборочным скриптом из этой рабочей копии. Сейчас в `.tmp/deps/installed` пять штампов: `Catch2`, `SDL`, `SDL_image`, `SDL_mixer`, `SDL_ttf`. Повторный прогон не собирает зависимости заново: в его логе по каждой зависимости есть строка `SKIP_DEPENDENCY`. Тесты и `tests/CMakeLists.txt`, которые ты написал в шаге 1, ведущий не менял.
2. **Поправка ожидания прогона A.** Фраза задания «каждый блок `CMake Error` из вывода `grep -A3` содержит `Cannot find source file` и путь, оканчивающийся на `src/utils/HouseMaskTint.cpp`» заменяется такой: «в выводе `grep -A3 "CMake Error"` по каждому из двух файлов (`.tmp/p6at/build-red-a.log` и `full.log` последней папки логов) ровно два блока, оба начинаются строкой `CMake Error at tests/CMakeLists.txt:<номер строки> (add_executable):`; первый блок содержит `Cannot find source file:` и путь, оканчивающийся на `src/utils/HouseMaskTint.cpp`; второй блок содержит `No SOURCES given to target: d2tm_tests`». Остальные ожидания прогона A не меняются: код выхода не 0, сборка останавливается на настройке CMake, строк `error:` нет.
3. **Что делать дальше.** Повтори прогон A той же командой из шага 2 с тем же именем лога `build-red-a.log`, затем продолжай по заданию: прогон B, шаг 3, сдача `## DONE-P6AT`. Остальные пункты задания не меняются.
