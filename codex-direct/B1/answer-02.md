- Порядок: SDL и Catch2 → SDL_image, SDL_ttf, SDL_mixer → сборка UP0 → `ctest` → запуск игры → скрипт → повторный запуск скрипта без пересборки → перенос в архив и полный прогон скрипта с нуля → `DONE-B1`.
- Параллельно: SDL и Catch2 одновременно; после установки SDL — SDL_image, SDL_ttf и SDL_mixer одновременно; каждая сборка ровно `-j16`.
- Помощники: не больше 3 одновременно, `gpt-6-luna` `xhigh`; им — сборка одной библиотеки по точному списку опций из `PLAN-B1-delta` и выжимки логов.
- Остановки: `Q` — правка кода UP0, загрузка не из разрешённых источников, превышение диска из поправки 1, красный тест UP0, нет строки перехода в `MENU` или код выхода не `124`, отсутствие ресурсов TiMidity мешает критерию запуска.
- Рамка правок: в рабочей копии — только `tools/upstream/build_up0_linux.sh`, `.tmp/` и сгенерированный `src/include/config.h`.
