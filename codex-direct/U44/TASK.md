# Задание U44 — новые карточки построек, юнитов и ударов Дворца

## Цель

Заменить 43 карточки игры картинками владельца. Карточки — записи `ICON_SPECIAL_*`, `ICON_STR_*` и `ICON_UNIT_*` пака `resources/bin/data/sdl_inter_hd4.dat`. Картинки владельца лежат в `/srv/dune/tasks/u44/src/`: 43 файла `<имя записи>.jpg`, файл только читается. Каждая картинка приводится к 256 × 192 RGB по правилу шага 2. Результат записывается в мастер карточки и в запись пака. Вид в игре оценивает владелец; сборки, CTest и запуск игры не нужны и запрещены, потому что код движка не меняется.

## Рабочая копия

`/srv/dune/worktrees/u34`, ветка `codex/u44-cards`, HEAD `fb749ae1`. Python — `/srv/dune/venv/bin/python` (Pillow есть). Перед командами git: `export PATH=/srv/dune/tools/git-lfs-3.6.1/usr/bin:$PATH`.

## Шаги

1. **Вход.** Расхождение в любом пункте ниже — блок `Q-U44-01` со строками вывода, затем стоп.
   - HEAD равен `fb749ae1`.
   - `git status --short` пуст.
   - sha256 пака начинается с `8ecf69b14ee2bece`.
   - В `/srv/dune/tasks/u44/src/` ровно 43 файла `.jpg`. Множество их имён без `.jpg` равно множеству имён записей пака, которые начинаются с `ICON_SPECIAL_`, `ICON_STR_` или `ICON_UNIT_`.
   - Для каждой из 43 записей в `resources/hd/master4/sdl_inter/` ровно один файл `<NNNN>_<имя записи>.png`. Здесь `NNNN` — поле `id` этой записи в `resources/hd/CARD_NAMES_RU.json`, четыре цифры с ведущими нулями.
   - Каждый такой мастер по пикселям RGB равен своей записи пака.
2. **Приведение к 256 × 192.** Скрипт — `.tmp/u44-tools/fit.py`. Каждая картинка открывается и переводится в RGB через `convert("RGB")`; дальше `w` и `h` — её ширина и высота. Все уменьшения делаются через `Image.LANCZOS`.
   - **Правило «целиком»** — ровно шесть записей: `ICON_UNIT_CARRYALL`, `ICON_UNIT_DEVASTATOR`, `ICON_UNIT_HARVESTER`, `ICON_UNIT_MCV`, `ICON_UNIT_QUAD`, `ICON_UNIT_SIEGETANK`.
     - Вычисли `fh = round(256 * h / w)`, `top = (192 - fh) // 2`, `bot = 192 - fh - top`.
     - Уменьши картинку до 256 × `fh` и вставь её в холст 256 × 192 RGB в точку (0, `top`).
     - Строки холста с 0 по `top - 1` — верхние `top` строк уменьшенной картинки, отражённые по вертикали (`ImageOps.flip`).
     - Строки холста с `top + fh` по 191 — нижние `bot` строк уменьшенной картинки, отражённые по вертикали.
     - Если `fh > 192`, напиши блок `Q-U44-02` и остановись.
   - **Правило «обрезка»** — остальные 37 записей.
     - Вычисли `cw = round(h * 4 / 3)` и `x0 = (w - cw) // 2`.
     - Вырежи прямоугольник (`x0`, 0, `x0 + cw`, `h`) и уменьши его до 256 × 192.
     - Если `cw > w`, напиши блок `Q-U44-02` и остановись.
   - Выход — `.tmp/u44-out/<имя записи>.png`, 43 файла, каждый 256 × 192 RGB.
3. **Лист.** `.tmp/u44-sheets/before-after.png` — по строке на каждую из 43 записей в порядке пака. В строке слева текущая запись пака, справа новый файл, оба 256 × 192; под строкой — имя записи.
4. **Установка.**
   - Каждый мастер из шага 1 заменяется одноимённым файлом `.tmp/u44-out/<имя записи>.png`, байты копируются без изменений.
   - Пак записывается через `hd_assets.write_pack`. Число записей и их порядок не меняются.
     - Меняются ровно 43 записи шага 1: данные каждой — `hd_assets.encode_png` от картинки одноимённого файла из `.tmp/u44-out/`.
     - Все остальные записи побайтно равны текущему паку.
   - Остальные файлы не меняются. Отдельно названы: `resources/hd/classic/`, `resources/hd/manifest.json`, `resources/hd/card_master_status.json`, `resources/hd/CARD_NAMES_RU.json`.
5. **Проверки.** Шаги 5а, 5б и 5в выполняются после шага 4.
   - а) `cd /srv/dune/worktrees/u34 && /srv/dune/venv/bin/python tools/verify_hd_card_catalog.py --repo .`. Ожидается первая строка `HD_CARD_CATALOG_OK`. Иначе — блок `Q-U44-03` со строками вывода, затем стоп.
   - б) `cd /srv/dune/worktrees/u34 && D2TM_PACK_DIR=$PWD/resources/bin/data /srv/dune/venv/bin/python -m unittest discover -s tools/building_angle/tests -v`.
     - Ожидается 21 тест и `OK (skipped=1)`; пропуск — с причиной `pack already holds an edge-to-edge Outpost`.
     - Тесты не меняй. Падение — блок `Q-U44-04` со строками вывода, затем стоп.
   - в) Сверка новым скриптом `.tmp/u44-tools/check.py`, по каждому пункту строка «да» или «нет» с числом:
     - каждая из 43 записей пака по пикселям RGB равна своему файлу из `.tmp/u44-out/`;
     - каждый из 43 мастеров побайтно равен своему файлу из `.tmp/u44-out/`;
     - все остальные записи побайтно равны паку до установки — его копию сделай до шага 4 в `.tmp/u44-tools/before-hd4.dat`;
     - записи `ICON_UNIT_RAIDER` и `ICON_UNIT_TRIKE` по пикселям RGB равны друг другу (у владельца для них одна картинка).

## Организация работы

- **Порядок:** шаг 1 → шаг 2 → шаги 3 и 4 → шаг 5 → `## DONE-U44` и стоп.
- **Параллельно:** шаги 3 и 4 не зависят друг от друга. Шаги 5а, 5б и 5в не зависят друг от друга.
- **Помощники:** нет; всё делает корневая нить.
- **Остановки:** только на `## DONE-U44` и на блоках `Q-U44-NN`.
- **Рамка правок:** `.tmp/`, `resources/bin/data/sdl_inter_hd4.dat`, 43 мастера `resources/hd/master4/sdl_inter/<NNNN>_<имя записи>.png`. Коммитов не делай.
