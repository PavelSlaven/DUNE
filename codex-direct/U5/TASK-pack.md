# Задание U5-pack — Харвестер группы C: масштаб D, шлейф у края кадра, пак

Режим: **«Ведёт sol»** (см. «Режимы задания» в конце). Исполнитель: Codex `gpt-6.1-sol` `high`; механика — субагентам `gpt-6-luna` `xhigh`.
Рабочая копия: `/srv/dune/worktrees/u8`, ветка `codex/u5-pack`: пак с группами A, B и D и инструмент с полем `offset_from` (доработка R11). Коммитов не делай: каталог git рабочей копии лежит вне песочницы, коммит делает ведущий. Правило «коммит на каждый законченный подпункт» из правил в конце к этому заданию не относится.

## Цель

Собрать новый Харвестер (`UNIT_HARVESTER`) под камерой 63° в масштабе D (решение владельца Р24): четыре ряда по восемь направлений. Ряд 0 — машина; ряды 1–3 — та же машина на том же месте и песчаный шлейф сбора спайса. Кадр игры — 320 × 208, корпус под 63° занимает почти всю его высоту, и шлейф у направлений k1, k2, k3 и k6 выходит за кадр. Решение ведущего: шлейф, который не помещается, плавно гаснет у края кадра; корпус не двигается и не обрезается. Установить в пак ветки тело, маску Дома и тень Харвестера.

В нём 32 записи: ряд 0 — попытки `harvester_k<k>_<попытка>.png` (1254 × 1254), выбор `pick` и перекраска `harvester_recolour_k<k>.png`; ряды 1–3 — составные кадры `harvester_r<r>k<k>_<попытка>.png` (1024 × 1024: корпус ряда 0 и наложенный шлейф), их перекраски `harvester_recolour_r<r>k<k>_<попытка>.png`, выбор `pick` ведущего и `"offset_from": 0`. Пути черновика — `/srv/dune/gen/UNIT_HARVESTER/…`; та же папка в рабочей копии — `units-gen/UNIT_HARVESTER/` (только читать). Файлы с окончанием `_s` не используются.

## Что сделать

1. **Описание.** `tools/units3d/units/UNIT_HARVESTER/unit.json` — копия черновика с изменениями, остальное без изменений:
   - пути `/srv/dune/gen/UNIT_HARVESTER/<имя>` записей ряда 0 — `units-gen/UNIT_HARVESTER/<имя>`;
   - пути попыток и перекрасок записей рядов 1–3 — `.tmp/out-c/cut/<имя>` (файлы пункта 3);
   - `"scale"` — `S × D`, округлённое до 6 знаков.
2. **Сборка ряда 0.** Описание с одними записями ряда 0 (`"rows": 1`) собери в `.tmp/out-c/row0/`. Код выхода не 0 из-за `clipped` — уменьшай `scale` на 0,005 и собирай заново в новую папку `.tmp/out-c/row0-<scale>/`, пока ряд 0 не пройдёт; итоговое значение `scale` впиши в описание пункта 1. Код выхода не 0 по другой причине — остановка `Q`. Из `params.json` прошедшей сборки возьми `offset` кадров `r0k0`…`r0k7`.
3. **Обрезка шлейфа во входах** (скрипт `.tmp/out-c/cut.py`). Для каждой записи (r, k) рядов 1–3 и каждой её попытки `<П>` из `a` и `b`:
   - `C` — составной кадр `harvester_r<r>k<k>_<П>.png`; `B` — попытка ряда 0 `harvester_k<k>_<p>.png`, где `p` — `pick` записи (0, k), уменьшенная до 1024 × 1024 (LANCZOS);
   - пиксель холста (X, Y) попадает в точку кадра x = (X + 0,5) · s / 1024 + dx − 0,5, y = (Y + 0,5) · s / 1024 + dy − 0,5, где s и (dx, dy) — из пункта 2 для направления k; расстояние до края кадра d = min(x, y, 319 − x, 207 − y);
   - множество `Z` — пиксели с d < 4, у которых пиксель `B` — фон (расстояние RGB от (255, 0, 255) не больше 60);
   - в `C` и в перекраске `harvester_recolour_r<r>k<k>_<П>.png` пиксели `Z` замени на (255, 0, 255); результат — `.tmp/out-c/cut/` под теми же именами.
   Так шлейф над фоном не выходит за кадр, а корпус и шлейф поверх корпуса не меняются.
4. **Полная сборка** описания пункта 1 в `.tmp/out-c/build/`. Код выхода не 0 — остановка `Q` со строками `metrics.txt`.
5. **Затухание у края** (скрипт `.tmp/out-c/fade.py`) — по атласам сборки пункта 4, результат в `.tmp/out-c/final/`. Для каждого кадра (r, k) рядов 1–3 и каждого его пикселя (x, y), x от 0 до 319, y от 0 до 207:
   - d = min(x, y, 319 − x, 207 − y); m = min(max((d − 4) / 20, 0), 1);
   - альфа тела A′ = max(H, round(A · m)), где A — альфа тела в кадре (r, k), H — альфа тела в кадре (0, k) в той же точке; RGB тела не меняется;
   - альфа маски Дома — min(альфа маски, A′);
   - тень кадра — заново из нового тела по `shadow_rule` описания тем же способом, что в `tools/units3d/redraw_build.py`.
   Ряд 0 всех трёх атласов не меняется. Запиши `atlases.json` трёх атласов в формате сборки. Скриптом сверь: ряд 0 трёх атласов попиксельно равен сборке; тень ряда 0, заново посчитанная тем же способом, попиксельно равна тени сборки; в рядах 1–3 A′ ≥ H всюду, A′ = 0 там, где d < 4 и H = 0, и тело с d ≥ 24 попиксельно равно сборке. Расхождение — остановка `Q`.
6. **Пак.** Копия `resources/bin/data/sdl_data_hd4.dat` — в `.tmp/out-c/pack-before.dat`; установи `.tmp/out-c/final/` через `install.py`. Скриптом сверь с копией: изменились ровно `UNIT_HARVESTER`, `HM_UNIT_HARVESTER`, `UNIT_HARVESTER_SHADOW`; размер каждого нового атласа равен размеру прежней записи; остальные записи совпадают байт в байт. Расхождение — остановка `Q`.
7. **Листы.** `redraw.py sheet tools/units3d/units/UNIT_HARVESTER .tmp/out-c/final .tmp/out-c/sheet-r<r>.png --row <r>` для r = 0 и r = 2. Ещё `.tmp/out-c/plume.png`: ряды 1–3, восемь направлений, тело из атласа пака пункта 6 с маской, окрашенной цветом Харконнена (`_tint`), тень под телом, песчаный фон RGB (200, 160, 110), рамка каждого кадра 320 × 208 линией RGB (120, 120, 120) толщиной 1 px, масштаб 1:1.
8. **Журнал** `codex-direct/U5/JOURNAL.md`: входы, итоговый `scale` и пробы пункта 2, правила пунктов 3 и 5 с числами, число пикселей `Z` по записям, строки `metrics.txt` пункта 4, три изменённые записи пака. Копии итоговых скриптов — `codex-direct/U5/cut.py` и `codex-direct/U5/fade.py`.
