# Разовые скрипты G3

Скрипты, которыми собран Девастатор G3 (Р21). Это запись способа, а не инструмент: пути рассчитаны на временную папку сессии, где рядом лежали `g2/` и `g3/`, а запуск шёл из корня репозитория с `PYTHONPATH` на папку скриптов. Основа будущего постоянного инструмента с тестами (карточка G3, раздел «Чего задача не делает»).

| Порядок | Скрипт | Что делает |
|---|---|---|
| 1 | `guide.py` | Blender: брусок-ориентир под 63° для каждого направления (запуск `blender -b --factory-startup --python guide.py -- <папка> <k…>`) |
| 2 | `make_inputs.py` | входы генерации 1024×1024 на пурпурном: старый кадр из пака и брусок |
| 3 | `contact.py`, `zoom.py` | листы попыток для глаза |
| 4 | `ratios.py` | пропорции силуэта каждой попытки против расчёта для 63° |
| 5 | `choose.py` | выбор попыток: зеркальные пары, разброс ширины, ошибка ракурса |
| 6 | `frames.py` | кадры 152×184 с одним общим масштабом, входы перекраски |
| 7 | `preview.py` | старые и новые кадры рядом на песке |
| 8 | `atlas.py` | маска Дома из зелёной перекраски, тень по правилу старого пака, три атласа и `atlases.json` |
| 9 | `pack.py` | копия пака репозитория с тремя заменёнными записями и сверка остальных байт в байт |
| 10 | `sheet.py` | лист «старый и новый» в цветах трёх Домов рядом с заводом |

`common.py` — общие части: доступ к паку, вырезка пурпурного фона (и чёрного, если генератор вернул чёрный), посадка кадра. `hm_probe.py` — проба маски по цвету (таблица цветов давала совпадение со старой маской только 0,40–0,69, поэтому маску даёт перекраска).

Числа прогона — `../choice.txt` и `../metrics.txt`.
