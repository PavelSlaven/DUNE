# NOTE-U11-S-01: сцена полосы здоровья здания

Поправка 4 файла `codex-direct/U11/PLAN-OK-shots-coverage.md` спорит с кодом в части сцены `structure-label`, и эта записка её заменяет. Ты записал это в журнал хода в 09:21:38 UTC. Игра рисует полосу здоровья только у одного здания — у того, над которым стоит указатель мыши: `cStructureDrawer::drawStructuresHealthBars` (`src/drawers/cStructureDrawer.cpp:41–50`) вызывает `drawStructureHealthBar` один раз, для `getIdOfStructureWhereMouseHovers()`. Поэтому в одном кадре не бывает двух записей `structure-health`, и сцена с двумя зданиями проверку пройти не может.

## Что меняется

1. Вместо сцены `structure-label` — две сцены: `structure-label-top` и `structure-label-right`. В каждой одно здание игрока `HUMAN`, указатель мыши стоит над этим зданием, в журнале одна запись `structure-health`. В сцене `structure-label-top` здание стоит у верхнего края области карты, в сцене `structure-label-right` — у правого. «Стоит у края» — по формулам поправки 4: у верхнего края `o.y − v.y ≤ o.h`, у правого края `(v.x + v.w) − (o.x + o.w) ≤ o.w`, где `o` — поле `owner` записи, `v` — поле `map_viewport` заголовка.
2. Проверка `check_scenes.py` для этих двух сцен:
   - ровно один объект с записью `structure-health`. Если объектов ноль или больше одного — отказ, в тексте причины есть слово `object`;
   - объект стоит у края, который назван в имени сцены. Если не стоит — отказ, в тексте причины есть слово `edge`;
   - иначе `OK`.
   Сцена с именем `structure-label` после правки проверкой не распознаётся, `check_scene` для неё возвращает `None`, как для любой непроверяемой сцены.
3. Правка замороженного файла `tools/ui-audit/tests/test_check_scenes.py` — только класс `StructureLabelScene`. Метод `records` остаётся. Четыре теста класса заменяются шестью:

   - `header("structure-label-right")` и `self.records([RIGHT])` дают `"OK"`;
   - `header("structure-label-top")` и `self.records([])` дают результат, в котором есть `"object"`;
   - `header("structure-label-top")` и `self.records([TOP, RIGHT])` дают результат, в котором есть `"object"`;
   - `header("structure-label-top")` и `self.records([MIDDLE])` дают результат, в котором есть `"edge"`;
   - `header("structure-label-right")` и `self.records([TOP])` дают результат, в котором есть `"edge"`.
   Больше в этом файле ничего не меняется.
4. Перечень проверок поправки 4 для сцен юнитов (`units-label-<тип>`) не меняется.
