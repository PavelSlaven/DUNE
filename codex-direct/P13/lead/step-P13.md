## Решения по шагу

1. **Объём.** Постоянный инструмент `tools/ui-audit/reference_shots.py` с тестами Python (`tools/ui-audit/tests/test_reference_shots.py`): по списку пар «сцена форка — сцена порта» и списку разрешений запускает исполняемый файл каждой сборки в режиме отладки интерфейса (`--ui-audit-scene`, `--ui-audit-out`, `-windowed`, `-screenWidth`, `-screenHeight`; точный набор аргументов каждой ревизии — из `screen-size.tsv` и `output.tsv`), собирает PNG и строит для каждой пары лист «старое | новое» рядом в одном PNG и таблицу `reference.tsv` (пара, разрешение, коды выхода, размеры PNG, пути). Работает на Linux и на Windows (имя `d2tm` / `d2tm.exe`, пути через `pathlib`). Список пар и разрешений — данные (файл `tools/ui-audit/reference_pairs.tsv`), не код.
2. **Экраны и разрешения** — семь экранов плана. Пары берутся из `screens.tsv`: по одной сцене форка и одной сцене порта на экран, которые показывают тот же экран в том же состоянии; где у форка сцены нет (схватка с боковой панелью), пара — сцена порта и «нет», лист показывает только новое. Бой (схватка и миссия) — при 800×600, 1920×1080 и 5120×1440; остальные экраны — при 1920×1080. Выбор пар — в задании таблицей с доводом из `scenes.tsv`; спорный выбор — в вопросы.
3. **Прогон на сервере** — только сборка порта (`B13`, Linux, драйверы SDL `dummy`/`software`): все пары, все разрешения; проверка — скрипт по `reference.tsv` (коды 0, PNG нужного размера). Сборка форка на сервере не делается (SDL2 на сервере нет, пакеты ставить нельзя): режим «только новое» и режим «старое из готовой папки PNG» инструмент поддерживает аргументами.
4. **Прогон на Windows и разбор отличий** делает ведущий после сдачи (старая сборка — выпуск `v0.8.0-ru-hd.10`, новая — сборка порта); исполнитель пишет в задании точную команду этого прогона для Windows, но не выполняет её.
5. **Галерея README (Р83).** Инструмент получает режим `--gallery`: пять сцен порта при 1920×1080 под именами пяти файлов `docs/screenshots/`. Какие сцены порта соответствуют пяти снимкам — определи по подписям `README.md@B13` и `scenes.tsv` и запиши в задании таблицей; нет подходящей сцены — вопрос.
