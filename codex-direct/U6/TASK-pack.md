# Задание U6-pack — маски Дома пехоты и отрядов, пак группы D

Режим: **«Ведёт sol»** (см. «Режимы задания» в конце). Исполнитель: Codex `gpt-6.1-sol` `high`; механика — субагентам `gpt-6-luna` `xhigh`.
Рабочая копия: `/srv/dune/worktrees/u8`, ветка `codex/u6-pack`. Коммитов не делай: каталог git рабочей копии лежит вне песочницы, коммит делает ведущий после приёмки. Правило «коммит на каждый законченный подпункт» из правил в конце к этому заданию не относится.

## Цель

Собрать маски Дома четырёх одиночных пехотинцев (`UNIT_SOLDIER`, `UNIT_TROOPER`, `UNIT_SABOTEUR`, `UNIT_SINGLEFREMEN`) по перекраскам сдачи `U6-rc` и маски трёх отрядов (`UNIT_SOLDIERS`, `UNIT_TROOPERS`, `UNIT_TRIPLEFREMEN`). Установить в пак ветки атласы тела и маски Дома всех семи записей, записать описания одиночных пехотинцев в инструмент и сделать листы в трёх цветах Домов. Правило окраски — решение владельца Р25: цвет Дома несут шлем, куртка, броня и штаны; маска берётся из перекрасок, старая маска пехоты образцом не служит.

## Что сделать

1. **Описания.** Для каждого `<ЮНИТ>` из четырёх создай `tools/units3d/units/<ЮНИТ>/unit.json` — копию `.tmp/out-u8/units/<ЮНИТ>/unit.json` с тремя изменениями, остальные поля и порядок кадров те же:
   - в `attempts` каждого кадра путь `.tmp/out-gen2/<ЮНИТ>/strip/frames/<имя>.png` заменён на `units-gen/<ЮНИТ>/<имя>.png`;
   - `atlases.house_mask` — `"HM_<ЮНИТ>"`;
   - у кадра (r, k) поле `recolour` — `units-gen/<ЮНИТ>/<базовое имя пути paths[r] записи k<k> юнита в selection.json перекрасок>`.
   Скриптом проверь: `pick` каждого кадра (r, k) равен `choices` направления k в `.tmp/out-gen2/<ЮНИТ>/strip/selection.json`; все пути описания существуют. Расхождение — остановка `Q`.
   Запиши `codex-direct/U6/gen/<ЮНИТ>.SHA256SUMS` — SHA-256 всех файлов `units-gen/<ЮНИТ>/` в формате образца.
2. **Сборка одиночных.** Для каждого `<ЮНИТ>`:
   - проба: в описание добавь `"share_corridor": [0.0, 1.0]`, собери `redraw.py build tools/units3d/units/<ЮНИТ> .tmp/out-pack/probe/<ЮНИТ>`; `M` — медиана столбца `share` по 32 кадрам `metrics.txt` пробы;
   - в описании замени `share_corridor` на `[M − 0,10, M + 0,10]`, оба числа округлены до 3 знаков; собери `redraw.py build tools/units3d/units/<ЮНИТ> .tmp/out-pack/<ЮНИТ>`.
   Сборка с кодом выхода не 0 (кадры с `iou`, `share` или `clipped` в `metrics.txt`) — остановка `Q` со строками `metrics.txt`. Скриптом сверь: атлас тела `.tmp/out-pack/<ЮНИТ>/<ЮНИТ>.png` попиксельно равен `.tmp/out-u8/<ЮНИТ>/<ЮНИТ>.png`; не равен — остановка `Q`.
3. **Отряды.** Добавь в `.tmp/squads/compose.py` ключ `--mask`. С ним `--source` — атлас маски Дома одиночного пехотинца, `--body` — его атлас тела. Сдвиги и порядок фигур те же, что без ключа (сдвиг — по рамке фигуры в `--body`; порядок — снизу вверх по нижнему краю, затем по номеру фигуры). Альфа маски отряда в каждом пикселе получается наложением фигур в этом порядке по формуле m ← m · (1 − a / 255) + μ, начиная с m = 0, где a — альфа тела фигуры, μ — альфа её маски после сдвига; итог округляется до целого. RGB пикселя маски — (255, 255, 255). Так маска задней фигуры не видна там, где её закрывает тело передней.
   Для каждого `<ОТРЯД>` собери в `.tmp/out-pack/squads/<ОТРЯД>/`:
   - тело `<ОТРЯД>.png` — `compose` без ключа: `--source` и `--body` — `.tmp/out-pack/<ОДИНОЧНЫЙ>/<ОДИНОЧНЫЙ>.png`;
   - маску `HM_<ОТРЯД>.png` — `compose --mask`: `--source` — `.tmp/out-pack/<ОДИНОЧНЫЙ>/HM_<ОДИНОЧНЫЙ>.png`, `--body` — `.tmp/out-pack/<ОДИНОЧНЫЙ>/<ОДИНОЧНЫЙ>.png`;
   - `atlases.json` в формате `atlases.json` сборки одиночного: записи `<ОТРЯД>` и `HM_<ОТРЯД>` с файлом, SHA-256 и размером.
   Скриптом сверь: тело отряда попиксельно равно `.tmp/out-u8/squads/<ОТРЯД>/<ОДИНОЧНЫЙ>_<ОТРЯД>.png`; альфа маски не больше альфы тела в каждом пикселе; маска непуста в каждом из 32 кадров. Расхождение — остановка `Q`.
   Скопируй места фигур в `codex-direct/U6/squads/<ОТРЯД>/placements.json` и итоговый скрипт в `codex-direct/U6/squads/compose.py`.
4. **Пак.** Сохрани копию `resources/bin/data/sdl_data_hd4.dat` в `.tmp/out-pack/pack-before.dat`. Установи в `resources/bin/data/sdl_data_hd4.dat` через `install.py --atlases <папка> --pack resources/bin/data/sdl_data_hd4.dat` семь папок: `.tmp/out-pack/<ЮНИТ>/` четырёх одиночных и `.tmp/out-pack/squads/<ОТРЯД>/` трёх отрядов. Скриптом сверь с копией: изменились ровно 14 записей — `<ЮНИТ>`, `HM_<ЮНИТ>`, `<ОТРЯД>`, `HM_<ОТРЯД>`; размер каждого нового атласа равен размеру прежней записи с тем же именем; остальные записи совпадают байт в байт. Расхождение — остановка `Q`.
5. **Листы.** Для каждой из семи записей тела — `.tmp/out-pack/sheets/<ЗАПИСЬ>.png`: три строки — Харконнен, Атрейдес, Ордос (цвета и окраска — `HOUSES` и `_tint`); в строке восемь направлений k0…k7, кадр ряда 0 из атласа пака пункта 4, маска окрашена цветом Дома; ×2; песчаный фон RGB (200, 160, 110); подписи — имя Дома слева.
6. **Журнал.** `codex-direct/U6/JOURNAL.md`: что собрано и из каких входов; `M` и `share_corridor` каждого одиночного; число кадров с `share` вне коридора пробы — 0 или список; команды сборки отрядов; список 14 изменённых записей пака. Замечание ведущего: у `UNIT_SOLDIER` в направлении k6 нагрудные подсумки перекрашены в цвет Дома, по Р25 они должны остаться своего цвета.

- Рамка правок: `tools/units3d/units/UNIT_SOLDIER/`, `tools/units3d/units/UNIT_TROOPER/`, `tools/units3d/units/UNIT_SABOTEUR/`, `tools/units3d/units/UNIT_SINGLEFREMEN/`, `codex-direct/U6/gen/`, `codex-direct/U6/squads/`, `codex-direct/U6/JOURNAL.md`, `resources/bin/data/sdl_data_hd4.dat`, `.tmp/out-pack/`, `.tmp/squads/compose.py`, `.tmp/progress-pack.md`; остальное, включая `units-gen/` и `/srv/dune/worktrees/u6/`, — только читать.

- Комментарии в коде. Категорически запрещено писать комментарий по принципу «полезен, если верен и относится к делу». По умолчанию комментария нет; он должен доказать право на существование: только неочевидное «почему» — инвариант, причина обхода, ссылка на внешнее ограничение. Пересказ кода, планы и история — нет. Внутренние номера находок, планов и решений (`F7`, `A-11b`, `D88`) в комментарий не писать: суть словами.
