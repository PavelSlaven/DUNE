- `### git status --short` рабочей копии.

## Организация работы

- **Режим:** «Ведёт sol».
- **Порядок:** пункты 1–7 в любом порядке → `## DONE-P1B-PR` и стоп.
- **Параллельно:** нет; проверка короткая.
- **Помощники:** нет; всё делает корневая нить.
- **Остановки:** только на `## DONE-P1B-PR` или на вопросе `Q-P1B-PR-NN`.
- **Рамка правок:** только `.tmp/pre-review-p1b/`. Ничего вне неё не меняй, не коммить.
