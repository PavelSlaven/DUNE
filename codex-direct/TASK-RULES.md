# Обязательные правила для исполнителя (дописываются в конец каждого задания)

## Среда servak

- Рабочая копия задания — папка, из которой тебя запустили (`/srv/dune/worktrees/<id>`). Писать можно только в неё. Временные файлы — только в `<рабочая копия>/.tmp/` (папка исключена из git через `.git/info/exclude`).
- Файлы Git LFS в этой копии — текстовые указатели, а не данные. Настоящие паки лежат вне репозитория, только для чтения: `/srv/dune/inputs/packs/` (`sdl_data.dat`, `sdl_data_hd4.dat`). Модели пилота — `/srv/dune/inputs/glb/`.
- Python с Pillow и numpy: `/srv/dune/venv/bin/python`. Blender 5.2.3 LTS: `/srv/dune/tools/blender-5.2.3-linux-x64/blender` (запускать с `-b --factory-startup`). Видеокарт нет: рендер только на CPU.
- Сети нет. Ничего не устанавливать и не скачивать. Чужие сервисы и папки вне рабочей копии не трогать, секреты не печатать.
- Без фоновых команд: после твоей остановки тебя никто не разбудит. Длинные прогоны — в переднем плане, с таймаутом не больше 30 минут.

## Git

- Ты не коммитишь: песочница открывает `.git` только для чтения. Коммиты в ветку `codex/<id>` делает ревьюер после проверки. Любые команды git, которые пишут (`add`, `commit`, `checkout`, `stash`, `reset`, `rebase`, `clean`, `push`), не запускать.
- После законченного подпункта — строка журнала хода со списком созданных и изменённых файлов. Временное и `.tmp/` в список не входят.

## Комментарии в коде

Категорически запрещено писать комментарий по принципу «полезен, если верен и относится к делу». По умолчанию комментария нет; он должен доказать право на существование: только неочевидное «почему» — инвариант, причина обхода, ссылка на внешнее ограничение. Пересказ кода, планы и история — нет. Внутренние номера находок, планов и решений (`F7`, `A-11b`, `D88`) в комментарий не писать: суть словами. Субагентам и исполнителям этот абзац передавать в бриф дословно.

## Порядок работы

- `create_goal` не вызывать: незакрытая цель запускает лишние автоматические ходы. После каждого сжатия контекста и перед каждым подпунктом перечитай раздел «Цель» задания.
- Механику (поиск, чтение, подсчёты, прогоны тестов, выжимки логов, код по ясному описанию) отдавай субагентам `gpt-6-luna` с усилием `xhigh`; сам — суждение, план, итоговая сверка. Бриф субагенту содержит абзац «Комментарии в коде» дословно.
- Делай продукт, а не доказательства: отчётных документов, квитанций и «официальных прогонов» не заводить. Доказательство — файл, тест и строка вывода прогона. Журнал хода — один файл `<рабочая копия>/.tmp/progress.md`, строка на законченный подпункт: что сделано, какие файлы, тест.
- Простейшее решение, которое полностью закрывает задачу. Не добавляй цели, результаты, настройки и защиту от случаев, которых нет в задании и в данных продукта. Сомнение, нужен ли случай, — неблокирующий вопрос в сдаче.
- Существующие тесты и их ожидания не менять; новый тест добавлять можно. Тест падает из-за программы — чинить программу.
- Дословное исполнение задания оставляет обход цели, отвергает честный случай или спорит с целью — блок `## Q-<id>-NN` и стоп до работы. Неблокирующий вопрос — записать в сдачу и работать дальше.
- Не утверждать прогон без лога; не выдумывать файлы, API, цитаты и результаты; непроверенное помечать «не проверено». Числа в сдаче — только из вывода команд.
- Один круг самоаудита на сдачу.
- План и сдача — буквальным языком: вместо «по возможности», «при необходимости», «и т. п.», «аналогично» — точный список, условие или число; вместо «это», «там», «такой» без ясного предмета — название предмета.

## Режимы задания

- **«План у ревьюера».** Первый ход — только блок `## PLAN-<id>` и стоп. В плане: каждое требование задания своими словами; источник истины по каждому; какие файлы изменишь и создашь; чем проверишь (команды); развилки с рекомендацией; объём; чего решение не закроет; какие шаги отдаёшь субагентам luna и скриптам. Работа — только после `PLAN-OK-<id>` от ведущего.
- **«Ведёт sol».** Ты сам делишь работу, одобряешь внутренние планы субагентов и не стоишь. Первой частью сдачи запиши `## PLAN-<id>` для записи (тот же состав). Стоп только на `DONE` или `Q`.
