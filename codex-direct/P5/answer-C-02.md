## Ответ на Q-P5C-02

Решение ведущего — дельта плана `PLAN-P5C-delta-02`.

1. В `cBuildingListDrawer::drawButton` вызов форка `logbook("ERROR UNABLE TO DRAW LIST BECAUSE ID IS NOT VALID!?")` не переносится. Остаётся вызов порта на том же месте: `Logger::error(COMP_GAME, "cBuildingListDrawer::drawButton","unable to draw list because id is not valid!? id={}", id);` без изменений.
2. То же правило действует для каждого вызова `logbook(...)` форка во всех файлах рамки правок: если в порту на том же месте есть вызов `Logger::...`, остаётся вызов порта без изменений; если вызова `Logger::...` на том же месте нет, вызов форка не переносится. По вызовам `logbook(...)` блок `## Q-P5C-NN` не нужен.

Продолжай шаг C/7 с того места, где остановился, затем дорожка D: проверки 1–6 задания. Всё остальное — по плану и дельте `PLAN-P5C-delta-01` без изменений. Не отступай от плана, не переусложняй.

Остановки прежние: блок `## DONE-P5C` или блок `## Q-P5C-NN`.
