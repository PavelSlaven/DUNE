## PLAN-P5A

Работу над кодом начну после `PLAN-OK-P5A`. Обязательные файлы задания прочитаны корневой нитью по одному; таблицы дорожек A, B и C сверены с исходными diff и кодом. Рабочее дерево чистое; до одобрения планов продуктовые файлы не менялись, сборка не запускалась.

### Решения и источники истины

- Все семь экранов получают логические размеры холста через `getScreenW()` и `getScreenH()`. Источники: контракт задания и настройки порта.
- Геометрию переношу по формулам и числам `FORK1`, с именами и способом доступа к данным порта. Исключения, разрешённые заданием: расчёт четырёх карточек выбора Дома и размещение портовых элементов, которых нет на экране форка. Источники: `git diff BASE FORK1` по файлам экранов, разделы «Что уже решено» и «Экраны».
- Состояния, их жизненный цикл, обработчики ввода, переходы и игровая логика остаются портовыми. Места портовых элементов без аналога у форка заданы отдельными строками таблиц ниже.
- Новые `CampaignMapLayout.hpp`, `OutcomeScreenLayout.hpp` и `TextAlignment.hpp` будут точными копиями `FORK1`. HD-загрузчик будет реализован по контракту задания; состояние удалит загруженные им текстуры. Источники: API-контракт задания, `src/utils/Graphics.hpp`, `src/include/Texture.hpp`, код загрузки и fallback в `FORK1`, `.tmp/p5a/recon/hd-ui.tsv`.
- GUI и текст переношу по `git diff BASE FORK1`, с исправлением требований из ответа на `Q-P5A-09`. Исходники состояния GUI и рисования текста в порту прочитаны.
- `tests/utils/test_AdaptiveMenus.cpp` и `tests/CMakeLists.txt` остаются неизменными. Если проверка после реализации выявит ошибку теста или противоречие теста контракту, тест не исправляется: оформляется блок `Q-P5A-NN` с выводом и работа останавливается.
- Коммитов, сетевых операций, установок пакетов и удаления файлов не будет. Новые комментарии в коде не добавляются.

### Развилки, которые выношу на одобрение

- **Главное меню:** `FORK1` рассчитывает панель на 7 кнопок, а в порту требуется сохранить 8 действий. Рекомендую сохранить формулу панели и вывести `buttonCount = 8` из числа портовых действий; прямоугольники всех восьми строк приведены ниже. Так сохраняются все действия порта без изменения формулы раскладки.
- **Карточки Дома:** применяются заданные формулы для четырёх карточек и сохраняется порядок портовых домов. Вычисленные прямоугольники приведены ниже.
- **GUI:** `REMASTER_BUTTON` получает значение `6`, поскольку в порту `WITH_STRETCHED_TEXTURE = 5`. Методы `GuiLabel::setText` и состояние доступности `GuiButton` уже существуют в порту, поэтому повторно не добавляются.
- **Настройка схватки:** `ERRATA.md` исправляет описание состояния PORT, а геометрию для переноса задаёт исходник `FORK1`: прямоугольник preview шириной `300`, при `x = W−302`. Эти исходные значения сохраню.
- **Экран исхода:** логику рисования из `cGame::drawOutcomeScreen` перенесу в `cWinLoseState`; ввод и переходы останутся портовыми.

### Проверки после одобрения плана

1. Выполнить `sha256sum -c .tmp/p5at/tests.sha256`. При несовпадении — `Q-P5A-01`.
2. Выполнить `df -m /srv`. Если доступно меньше 5000 MB — `Q-P5A-02`. Иначе выполнить заданную команду сборки:

   ```bash
   DUNE_DEPS_DIR=$PWD/.tmp/deps DUNE_OUT_DIR=$PWD/.tmp/out bash tools/upstream/build_upstream_linux.sh d06f2fcd2a347182c3774fb96e9a85570405c489 > .tmp/p5a/build.log 2>&1
   ```

   Проверить код выхода, предупреждения рамки правок в `full.log`, итог `ctest.log`, количество и результаты тестов `P5A`, `P4B`, `P4`, `P3`. При провале — `Q-P5A-03` с требуемыми строками логов.
3. Проверить `game-dummy.log` и `stdout-dummy.log` по условиям задания. При несоответствии — `Q-P5A-04`.
4. Выполнить три заданных `git show … | cmp`, `git grep -l "loadHdUiTexture(" -- src`, `git grep -n -E "command_bar|_ru\.png" -- src` и сверку `.gitattributes` и `resources/bin/data/hd4`. При несоответствии — `Q-P5A-05`.
5. Выполнить `git -c lfs.storage=$PWD/.tmp/p5a/lfs status --short` и сверить только разрешённые пути. При лишних строках — `Q-P5A-06`.

Номера команд и проверяемые условия берутся из раздела «Проверки» задания. До `PLAN-OK-P5A` эти команды не запускаются.
