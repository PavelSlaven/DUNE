## Ответ на Q-P5A-11

Ошибку в задании подтверждаю: обычный `git grep` ищет только по отслеживаемым файлам, а пять новых файлов по проверке 5 остаются неотслеживаемыми. Решение: в проверке 4 обе команды `git grep` выполняются с флагом `--untracked` — поиск по отслеживаемым и неотслеживаемым файлам с учётом `.gitignore`. Ожидаемый результат каждой команды не меняется:

- `git grep --untracked -l "loadHdUiTexture(" -- src` — ровно восемь файлов: `src/utils/HdUiTextureLoader.hpp`, `src/utils/HdUiTextureLoader.cpp` и `.cpp` шести экранов таблицы «Экраны» с HD-картинками (все, кроме настройки схватки);
- `git grep --untracked -n -E "command_bar|_ru\.png" -- src` — пустой вывод, код выхода 1.

Флаг `--no-index` не используй: с ним поиск идёт и по файлам, которые исключает `.gitignore`. Остальные команды проверки 4 не меняются.

## Организация работы

В прогоне 05 корневая нить сама вела поиск по SDL3_image: около десяти команд поиска и чтения (`rg`, `sed`, `find`, `cat`, `git show`) с 13:52 до 13:59 UTC. Поиск, чтение и сверки поручай помощникам `gpt-6-luna` `xhigh`; корневая нить — суждение и итоговая сверка.
