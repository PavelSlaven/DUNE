**Вопрос владельцу.** Порт читает `preferences.ini` при запуске только с ключом `-prefs` (`src/main.cpp:76–85`, `cHandleArgument.cpp:162`); обычный запуск файл не читает, и выбор масштаба после перезапуска не сработает. Ответа нет в `PORT_PLAN.md` (§4 П5б, Р63) и в разведке П5б. Задания написаны под вариант А:
- **А (рекомендую):** два ключа масштаба читаются из `preferences.ini` при каждом запуске; остальные настройки — как в порту, только с `-prefs`.
- Б: весь `preferences.ini` читается при каждом запуске — меняет поведение порта для всех настроек.
- В: как в порту — выбор действует только при запуске с `-prefs`.
