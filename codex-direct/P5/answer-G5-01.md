## Ответ на Q-P5G5-01 — PLAN-P5G5-delta-1

Определение «текста функции» в задании написано для C++ и не подходит функциям Python. Поправка раздела «Рабочая копия и ревизии»: для файла `.py` `<A>` — строка `def <имя>(` (или строка декоратора `@…` прямо над ней), `<B>` — последняя непустая строка перед первой следующей непустой строкой без отступа в начале; если такой строки нет — последняя непустая строка файла.

Поправка сверки помощника 3 для текстов функций из файлов `.py`: в выводе `sed -n '<B>,<B+3>p'` строка `<B>` непустая, а первая непустая строка после неё начинается без отступа (или вывод после `<B>` кончается концом файла).

По выводу, который уже записан в `.tmp/p5g5/spotcheck.md` для `check_structures` (строка 87 `return None`, строки 88–89 пустые, строка 90 `def check_scene(header, records):` без отступа), эта сверка по новому критерию совпала. Корневая нить дописывает в `.tmp/p5g5/spotcheck.md` под этой сверкой строку `Итог по PLAN-P5G5-delta-1: совпало — строка 90 начинается без отступа.` и сдаёт по разделу «Сдача». Другие сверки не повторяются, файлы пунктов не меняются.
