## Цель

В атласах тела всех юнитов, собранных инструментом `tools/units3d/redraw.py`, у края силуэта осталась кайма — смесь края с пурпурным фоном генерации (255, 0, 255). Очистка края уже в `main`. Пересобрать атласы этих юнитов из их описаний в `main`, поставить их в пак `resources/bin/data/sdl_data_hd4.dat` рабочей копии и скриптом доказать, что изменился только цвет пикселей у края тела, а форма, маски Дома, тени и остальные записи пака — прежние.

## Что сделать

1. **Прежний пак.** Скопируй `resources/bin/data/sdl_data_hd4.dat` в `.tmp/rebuild/pack-before.dat`; строку `sha256sum` обоих — в журнал.
2. **Сборка 16 юнитов** — все папки `tools/units3d/units/UNIT_*`, кроме `UNIT_HARVESTER`: `/srv/dune/venv/bin/python tools/units3d/redraw.py build tools/units3d/units/<ЮНИТ> .tmp/rebuild/<ЮНИТ>` из корня рабочей копии. Код выхода не 0 или нет строки `all frames pass` — остановка `Q` со строками `metrics.txt`.
3. **Харвестер.** `/srv/dune/venv/bin/python tools/units3d/redraw.py build tools/units3d/units/UNIT_HARVESTER .tmp/out-c/build`, затем `/srv/dune/venv/bin/python codex-direct/U5/fade.py` (скрипт читает `.tmp/out-c/build/` и пишет `.tmp/out-c/final/`, `.tmp/out-c/fade.log`). Папка `.tmp/out-c/` до запуска не должна существовать; существует — остановка `Q`. Код выхода не 0 или в `fade.log` нет строки `result: PASS` — остановка `Q` с текстом `fade.log`.
4. **Отряды.** Для каждой пары «отряд ← одиночный»: `UNIT_SOLDIERS` ← `UNIT_SOLDIER`, `UNIT_TROOPERS` ← `UNIT_TROOPER`, `UNIT_TRIPLEFREMEN` ← `UNIT_SINGLEFREMEN` — две команды:
   - тело: `/srv/dune/venv/bin/python codex-direct/U6/squads/compose.py compose --squad <ОТРЯД> --source .tmp/rebuild/<ОДИНОЧНЫЙ>/<ОДИНОЧНЫЙ>.png --body .tmp/rebuild/<ОДИНОЧНЫЙ>/<ОДИНОЧНЫЙ>.png --placements codex-direct/U6/squads/<ОТРЯД>/placements.json --out-root .tmp/rebuild --output .tmp/rebuild/squads/<ОТРЯД>/<ОТРЯД>.png`;
   - маска: та же команда с `--mask`, `--source .tmp/rebuild/<ОДИНОЧНЫЙ>/HM_<ОДИНОЧНЫЙ>.png` и `--output .tmp/rebuild/squads/<ОТРЯД>/HM_<ОТРЯД>.png`.

   Затем запиши `.tmp/rebuild/squads/<ОТРЯД>/atlases.json`: `{"entries": {"<ОТРЯД>": {"file": "<ОТРЯД>.png"}, "HM_<ОТРЯД>": {"file": "HM_<ОТРЯД>.png"}}}`. Имена файлов тела и маски одиночного берутся из `atlases.json` его сборки; не совпадают с шаблоном выше — остановка `Q`. Код выхода не 0 — остановка `Q`.
5. **Установка.** `/srv/dune/venv/bin/python tools/units3d/install.py --atlases <папка> --pack resources/bin/data/sdl_data_hd4.dat` по очереди для 20 папок: 16 папок `.tmp/rebuild/<ЮНИТ>/` пункта 2, `.tmp/out-c/final/` и три папки `.tmp/rebuild/squads/<ОТРЯД>/`.
6. **Проверка** — скрипт `.tmp/rebuild/verify.py` (запуск `/srv/dune/venv/bin/python -I`), читает оба пака функцией `read_pack` из `tools/hd_assets.py`, картинки — Pillow в RGBA, расстояния — `scipy.ndimage.distance_transform_edt`. Правила:
   1. Число записей, их порядок, имена и расширения в обоих паках равны.
   2. Запись, которой нет ни в одном `atlases.json` 20 папок пункта 5, — payload побайтно прежний.
   3. Записи из `atlases.json`: размер картинки прежний.
   4. Записи масок Дома (имя начинается с `HM_`) и теней (имя кончается на `_SHADOW`): все четыре канала каждого пикселя прежние. Payload, отличный побайтно при равных пикселях, — не нарушение; список таких записей — в сдачу.
   5. Записи тела (остальные записи из `atlases.json`; их 20): альфа каждого пикселя прежняя; канал G каждого пикселя прежний.
   6. У 17 записей тела, кроме трёх отрядов: каждый пиксель, у которого изменился R или B, лежит не дальше 10 пикселей от пикселя с альфой 0 той же картинки (`distance_transform_edt(alpha > 0)` в этом пикселе не больше 10).
   7. По каждой записи тела в отчёт `.tmp/rebuild/verify.tsv` (строка на запись): имя; число пикселей силуэта (альфа больше 0); число пикселей с изменённым R или B и их доля в силуэте; наибольшее расстояние такого пикселя до альфы 0; число пикселей каймы до и после — альфа больше 0 и min(R, B) − G не меньше 40 — и доля каймы в силуэте до и после.

   Нарушение правил 1–6 — остановка `Q` со строками отчёта: имя записи, правило, число пикселей-нарушителей и до пяти их координат.
7. **Лист для ведущего** — скрипт `.tmp/rebuild/sheet.py`, файл `.tmp/rebuild/sheet.png`. Для каждой из 20 записей тела — кадр строки 0, направления k = 1 (ячейка `[k · fw, 0, (k + 1) · fw, fh]`, где `fw × fh` — поле `frame` описания юнита; у отряда — `frame` описания его одиночного): прежний и новый кадр, каждый наложен на песок RGB (200, 160, 110) и увеличен в 3 раза ближайшим соседом; прежний слева, новый справа, над парой — имя записи. Пары — сеткой по 4 в ряд.
