## Что сделать

1. **#46, замер.** Собери игру в `.tmp/build`. Запусти без окна (SDL offscreen, как аудит `tools/ui-audit/`) два прогона по 600 кадров одной и той же сцены — затухание интро региона и затем игровая карта: 2560×1440 HD, масштаб рендера и мира «авто»; 1920×1080 HD, те же настройки. Для каждого прогона — медиана, 95-й процентиль и максимум времени кадра в миллисекундах. Время кадра бери по таймеру вокруг кадра; таймер добавляй только во временную копию исходников `.tmp/src-timing/` и собирай её отдельно в `.tmp/build-timing`.
2. **#46, медленный путь.** Для прогона 2560×1440 — 10 функций с наибольшей долей времени (профилировщик `perf`, если он есть на servak, иначе `gprof` по сборке с `-pg` в `.tmp/build-prof`; какой взят — в сдаче) и одна-три фразы, какой путь отрисовки делает 2560×1440 медленнее 1920×1080, со ссылками файл:строка.
3. **#60, по каждому юниту.** Для `UNIT_SIEGEBASE`, `UNIT_HARVESTER`, `UNIT_TANKTOP`, `UNIT_SIEGETOP`: пересборка `redraw.py build` из описания main `b2bac6d0` во `.tmp/u28-build/`; число различающихся пикселей тела, маски и тени против записей пака (декодированные RGBA). Для каждой отличающейся записи: последний коммит, который менял эту запись в паке (сообщение, задача U<N>), и шаг этого коммита, которого нет в описании (сдвиг клеток, перекраска, правка вручную); и какие изменения описания или входов дали бы побайтную пересборку — или почему побайтная пересборка невозможна.
4. **#3, объём.** Скриптом по всем `tools/units3d/units/*/unit.json`: каждый путь входного файла (картинки попыток, перекраски, модели), есть ли он в git этой копии, на servak вне репозитория (полный путь) или нигде; размер каждого; суммы по юнитам и итог; отдельно — сколько весят только выбранные попытки (`attempts[pick]`) и перекраски. Пути и размеры — файлом `.tmp/u28-inputs.tsv`, итоги — в сдаче.
