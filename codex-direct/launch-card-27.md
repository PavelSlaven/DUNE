## План

Волна 4 — перенос. Каждый шаг — отдельная задача Codex: задание пишет ведущий, у шага своя ветка и свой PR. Код и данные игры в `main` не меняются до шага П14; в `main` идут только документы процесса (решения, карточки, задания) и карта переноса.

1. **П1. Свежая база и карта** — первая задача, её запускает эта карточка.
   - Закрепить `UP1` — master апстрима на момент запуска. SHA записывается в задание.
   - Перевести `tools/upstream/port_inventory.py` и `tools/upstream/port_features.json` на `FORK1 = 9208dcf5` (наш `main` с релизом hd.10) и на `UP1`.
   - Добавить функции форка, появившиеся после `6662b2f4`.
   - Пересобрать `docs/upstream/PORT_MAP.md` и `docs/upstream/port_inventory.json`; тесты карты должны проходить.
   - Доработать скрипт сборки апстрима (пункты Б1н), собрать `UP1` и прогнать его тесты на Linux (servak). Сборку на Windows делает ведущий на ПК, механику — субагент Sonnet.
   - Создать ветку порта `port/up-<UP1>` от `UP1`.
   
   Исполнитель — Codex `gpt-6-luna` `xhigh` на servak. Рабочие копии — `b1` (апстрим) и `u34` (форк; задача U45 слита). Предревью — `gpt-6.1-sol` `high`.
2. **П2–П12** — шаги Б2–Б12 плана по порядку карты П1:
   - слой данных и паки;
   - загрузка HD4 и рендер;
   - адаптивные меню;
   - цвета Домов;
   - RU/EN;
   - сохранения;
   - музыка;
   - панель приказов;
   - ментаты и сцены;
   - упаковка релиза.
   
   На каждом шаге приёмочные тесты до начала пишет `gpt-6.1-sol` `high`, исполняет `gpt-6-luna` `xhigh`, предревью делает `gpt-6.1-sol` `high`.
3. **П13.** Эталонные снимки старой и новой сборки и разбор отличий (Б13).
4. **П14.** Догоняющий merge апстрима, связывание истории и перемотка `main` (Б14). До перемотки владелец принимает новую сборку в игре.
5. **П15.** Документ и скрипт регулярного обновления с апстрима (Б15).

Шаги П2–П15 запускаются без новых карточек. Смена подхода или рамки — новая карточка.

**Вопрос владельцу на шаге упаковки релиза.** В `UP1` есть новый workflow `.github/workflows/claude-code-review.yml`. Он запускает ревью приложением Claude Code GitHub App и ключом `ANTHROPIC_API_KEY`. На `PavelSlaven/DUNE` приложение не установлено, поэтому проверка `claude-review` падает на каждом PR в ветку порта (впервые — PR #102, 2026-11-09). Варианты: владелец устанавливает приложение и добавляет ключ, или workflow удаляется из форка. На остальное переноса падение не влияет.
