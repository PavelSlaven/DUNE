# План U: перерисовка всех юнитов игры под камеру 63°

Ведёт ведущий (Claude Opus 5.5). Живой статус — issue #1; здесь — состав работы, способ и правила. Ветка интеграции — `units63/main` от `main`.

## Цель и решения

Все юниты игры перерисовываются из своих HD4-спрайтов под угол камеры θ = 63° с сохранением дизайна, материалов и окраски (Р20, Р12). Способ отработан и принят на Девастаторе (Р21, `codex-direct/G3/`). Работа — одной большой задачей, автономно, на servak (Р22).

## Способ (по G3)

1. **Входы.** Старый кадр, вписанный по высоте в холст 1024×1024 на пурпурном фоне; брусок-ориентир 63° из Blender с носом-стрелкой. Размеры бруска — по силуэту старого кадра юнита.
2. **Генерация.** Промпт В2 с текстом направления, две попытки на кадр; повтор — только по числовым правилам (нет юнита, обрезан, текст, нарисован брусок, фон не пурпурный по угловым пикселям).
3. **Выбор попытки** — скриптом: пропорции силуэта против расчёта для 63°, согласие зеркальных пар, разброс ширины. Облик проверяет ведущий по листу.
4. **Кадр.** Один масштаб на юнит — медиана «ширина старого / ширина нового» по направлениям; центр рамки — в центр старой рамки; при выходе мягкого края за кадр — сдвиг внутрь.
5. **Маска Дома.** Генератор перекрашивает в чистый зелёный те части, что окрашены цветом Дома в старом спрайте; опора — второе изображение: старый кадр, где части под старой маской залиты зелёным. Приёмка: силуэт перекраски совпадает с кадром (IoU ≥ 0,97), доля маски — в коридоре старой доли ± 0,05. Осадный — как в старом паке, без изменения доли (Р18 по смыслу).
6. **Тень.** Правило старого пака: силуэт со сдвигом и постоянной прозрачностью; сдвиг и прозрачность подбираются по старому паку каждого юнита. Совпадение со старой тенью по правилу — корреляция ≥ 0,95; ниже — разбор, тень не выдумывается.
7. **Анимация** (ряды): все кадры одного направления — одной генерацией полосой, чтобы кадры не расходились. Проба — на Орнитоптере (группа C) и Солдате (группа D) до остальных.
8. **Башня отдельно** (Танк, Осадный): корпус и башня перерисовываются отдельно; точка крепления башни проверяется сборкой «корпус + башня» по всем направлениям против старой сборки. Проба — на Танке.
9. **Сборка.** Атласы прежнего размера, замена только записей юнита в паке со сверкой остальных байт в байт; лист «старый / новый» в цветах трёх Домов.

- Внутри плана шаги идут без вопросов тебе. Вопрос — только необратимое, деньги, доступы, AGENTS.md и governance.
- Твоя проверка в игре — после групп A, B–C и D–E; работа следующей группы её не ждёт. Замечание — правка в той группе.

- Стоп и разбор: обе попытки кадра ломают дизайн или ракурс после повтора; маска или тень вне правил после повтора; второй возврат того же рода; тупик — проход Opus по артефактам.

- Диск servak: рабочая копия и генерации лежат на корневом томе (после клонирования свободно около 8 ГБ). Меньше 5 ГБ свободно — стоп и вопрос тебе об отдельном томе для DUNE; чужие диски не занимаю.
