DUNE II — The Maker RU/HD — Windows x64
=======================================

1. Download the matching common-assets ZIP from the same GitHub Release.
2. Extract this ZIP and common-assets into the same empty directory.
3. Run d2tm.exe.

The required MinGW and SDL2 DLLs are included in this platform archive.
Windows may warn about an unsigned executable. This build is produced by the
public GitHub Actions workflow and is not digitally signed.

Back up settings.ini, music and saves before replacing an older installation.
